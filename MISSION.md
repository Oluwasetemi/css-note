# Mission: Practical CSS container queries

## Why

Learn to build reusable UI components that adapt to the space they actually receive, rather than guessing from the viewport. The immediate goal is to understand Josh W. Comeau’s two container-query articles well enough to recognize and apply their central pattern in real layouts.

## Success looks like

- Choose correctly between a media query and a container query.
- Create an inline-size query container and style its descendants.
- Explain why containment is required and why `inline-size` is usually safer than `size`.
- Replace fragile viewport “magic numbers” with one intentional component breakpoint.
- Use named containers when a component has multiple container ancestors.

## Constraints

- Teach the concept step by step in a self-contained, interactive HTML lesson.
- Emphasize practical application and usefulness rather than API memorization.
- Ground explanations in the supplied articles and primary CSS documentation.

## Out of scope

- Style queries, scroll-state queries, and anchored container queries.
- Exhaustive browser-history or CSS-containment performance optimization coverage.
